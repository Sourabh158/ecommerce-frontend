🛒 E-Store Full-Stack Frontend
This is a modern E-commerce frontend built with Angular 18, featuring a complete shopping experience and an administrative dashboard.

🚀 Key Features
Admin Dashboard: Effortlessly manage products (Add, Edit, Delete) and categories.

Real-time Search & Filter: Users can instantly search for products by name or filter by category.

Shopping Cart: Fully functional cart management system for seamless shopping.

Responsive Design: Optimized for various screen sizes using Bootstrap 5.

🛠️ Tech Stack
Framework: Angular 18+

State Management: Service-based architecture for Cart and Auth.

Styling: Bootstrap 5 and custom CSS.

Backend Integration: Connected via REST APIs to a Spring Boot service.
